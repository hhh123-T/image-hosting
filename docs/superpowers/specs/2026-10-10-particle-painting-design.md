# 颜料粒子画境

用户要求把画境改成粒子形态，提升视觉冲击，消除明显的几何棱角。保留先前要求的粉白、灰蓝、赭红、炭黑与巨大空间，TypeScript 实时三维、连续运镜和可下载视频。

使用现有场景作为不可见的空间采样骨架，表面与边缘均转为立体颜料点群。主体点群具有厚度、非平面的扰动、稀疏边缘和卷动轨迹；220,000 个主体点、27,500 个柔和颜料云点、55,000 个环境点和26,000 个水上点组成 328,500 个独立点。倒影共享主体几何，提交的点顶点上限为 548,500，倒影中约 73% 在顶点阶段隐藏。相机仍按 48 秒连续闭合路径接近、穿过、抬升、环绕。流动和聚散也在 48 秒闭合，纸纹固定，避免闪烁。

原有颜料样本负责逐点颜色。主画面不显示建筑三角面、规则边线或镜面水面。粒子为不规则的墨点与短笔触，使用空间深度、点尺度、雾、柔光与画面颗粒形成层次。原有播放、拖动、画幅、减少动态效果和恢复提示继续可用。

用户追加要求整个画面具有包裹性背景，避免与原画相差太大。背景必须包含围绕镜头的多层灰蓝晕染、粉白雾层和不规则炭黑墨团，从正面、侧面与抬升角度均可看见。背景使用连续油彩底色加立体墨团和点群，填满远处空隙并形成巨大纵深，不能只留下灰色天空或孤立粒子主体。

背景全景参照已有颜料样本生成，覆盖 360 度远景；侧边采用柔和混合避免明显拼接。全景加载独立于主体，慢加载时先显示粒子与程序晕染，完成后即使暂停也更新画面。离线截图和视频等待全景完成或备用状态，避免导出过程中底色变化。

验收：真实 Chromium 中确认主体只有点群，粒子位置与颜色有效且生成可复现，提交点数不超过 550,000；纹理失败时仍有可见备用粒子；检查两种画幅的八个运镜时刻。导出实际场景，验证帧数、完整解码、黑帧与 GitHub 下载文件一致性。
