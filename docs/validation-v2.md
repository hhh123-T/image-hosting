# 绘画质感第二版验证 · 2026-10-10

## 视觉修改

- 色彩改为冷灰蓝、粉白、炭黑和赭红，降低绿雾与暖色偏光。
- 粉白与赭红在阴影中保留颜料本色；炭黑包含灰色笔触，避免大块细节压成纯黑。
- 加入参照画作生成的油彩/刮擦材质样本；白墙、横梁、岩体与红色切面使用独立颜料纹理。
- 纹理在物体 UV 上，各个面随相机转动保留绘画表面。画面渲染增加沿轮廓的刷痕、纸纹与颜料边缘。
- 水面使用灰蓝干刷、横向刮痕和模糊晕染倒影；粒子为低透明度灰黑颜料碎屑。
- 主体加宽白墙与红色切面，加入不规则炭黑体块。移除第一版的圆环与规则悬空阶梯。
- 相机从更近处接近、穿过门廊、抬升并环绕，48 秒闭合。静态建筑使用缓存阴影，所有动态效果按 48 秒周期更新。

## 验证结果

- `npm test`：7/7 通过。
- `npm run test:e2e`：8/8 通过，在真实 Chromium 软件 WebGL 中检查渲染、播放、拖动、快捷键、移动布局、减少动态效果和完整相机路径。
- 颜料接缝回归检查经历失败/通过验证：将实际球面接缝 UV `u=1.05807` 渲染为炭黑，旧材质采到邻近赭红；四块独立纹理修复后保持炭黑。独立 mipmap 同时避免远景色块混入。
- `npm run build`：TypeScript 检查与生产构建通过。Vite 仍给出 Three.js 主包超过 500 kB 的提示。
- 最终生产构建检查了方形与竖屏各八个时刻，共 16 张实际渲染画面；涵盖接近、穿行、抬升和环绕，全程无浏览器报错。
- 独立只读代码审查验证了 182 个源盒体与六组实例绘制的变换等价、相机对岩体的实际三角形间距，以及加载中和加载后的纹理清理。
- 天空与水面借用材质拥有的灰蓝纹理，不重复持有独立 GPU 资源。四个纹理与实例缓冲都有释放路径。

导出使用浏览器中的实际三维场景按时间逐帧采样，关闭导出页面中进度条的步进取整，以 `frame / fps` 的精确时间采样。输出时间与云端渲染速度无关。硬件加速设备的实时帧率未在本云环境测量。
