# 颜料粒子版验证

2026-10-10，Node.js 24，TypeScript 7，Three.js 0.186，Chromium / SwiftShader。

- 单元测试：10/10 通过，覆盖播放、闭合镜头、实际网格的粒子位置/颜色、立体厚度和固定种子复现。
- 浏览器检查：11/11 通过，覆盖原有操作、路径碰撞、纹理采样接缝、正常/失败纹理下的粒子世界、点顶点预算上限与 48 秒相位闭合。
- 延迟全景测试先在旧实现失败（主体一直处于 loading），改为独立加载后通过；暂停状态下全景完成前后的实际画布截图不同。
- TypeScript 检查与生产构建通过。
- 生产包在方形 900×900、竖屏 720×1280 的 0、6、12、18、24、30、36、42 秒共 16 张截图中没有浏览器错误；检查近景、穿行、抬升与环绕，背景覆盖整个画面。
- 独立审查发现并修复全景阻塞主体加载的问题；程序背景经度边界改为连续方向噪声，全景边缘柔和混合。更新粒子预算说明及上限检查。
- 审查中的 CPU 资源探针确认共享几何只释放一次；加载中销毁后没有添加迟到粒子，迟到纹理被释放。暂停画面在素材变化后重新渲染。

主体共 328,500 个独立点；倒影共享主体几何，总提交顶点 548,500。软件渲染截图仅证明功能和画面输出，不能作为用户设备的实时帧率承诺。

原画作为视觉参考，颜料样本与环绕全景是参照其风格生成的素材；当前作品属于风格化三维粒子演绎。
