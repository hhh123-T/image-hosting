# 绘画颜料材质

`paint-atlas.png` 是参照用户所提供原画的视觉语言生成的四种材质样本：粉白厚涂、灰蓝干刷、炭黑竖向笔触和赭红油彩。第三版用它读取三维粒子的颜料颜色与背景底纹。

加载时四个色块被分别裁切为独立 sRGB 纹理，保证球面 UV 接缝和重复采样不会混入相邻色块。第三版按不可见采样骨架的 UV 读取这些色块，转换为立体粒子的颜色。程序生成的笔触提供加载失败时的备用材质。

`ink-panorama.png` 是参照这组颜料样本生成的环绕背景，包含厚涂刮痕、粉白雾层、灰蓝远景、炭黑墨团、少量赭红和银灰水面。它用于 360 度远景球面，近处仍由实际三维粒子构成。全景加载失败时使用连续程序晕染，加载较慢时不会阻塞主体出现。
